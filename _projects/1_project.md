This project brings together my doctoral research at University College of Engineering, Osmania University, supervised by Prof. Ram Mohan Rao Kovvur.

The goal is an **intrusion detection system (IDS)** that uses deep learning both to _detect_ malicious network traffic and to _classify_ it by attack type, rather than only flagging traffic as normal or anomalous.

#### Related publications

- RAP-DenseNet Framework for Network Attack Detection and Classification. _Journal of Information & Knowledge Management_, World Scientific, 2024. [DOI](https://doi.org/10.1142/S0219649224500333)
- A model for multi-attack classification to improve intrusion detection performance using deep learning approaches. _Measurement: Sensors_, Elsevier, 2023. [DOI](https://doi.org/10.1016/j.measen.2023.100924)
- An advanced intrusion detection algorithm for network traffic using convolution neural network. _ICECCT 2023_, IEEE. [DOI](https://doi.org/10.1109/ICECCT56650.2023.10179767)
